# C Multiple-Purpose Function Libraries

## Overview

This repository contains a collection of **reusable C utility libraries**, **exam solutions**, **book exercises**, and **reference materials** developed during the **Informática 1** course at the **Universidad Tecnológica Nacional — Buenos Aires (UTNBA)** in **2022**.

It serves as a professional portfolio of C programming skills covering data structures, file I/O, networking, sorting algorithms, string manipulation, and more.

> 📖 For the Spanish version of this document, see [README_ESP.md](README_ESP.md).

---

## Repository Structure

| Folder | Description |
|---|---|
| **Libraries/** | Reusable C utility functions organized by topic (Strings, Sorting, LinkedLists, Matrix, FileIO, Math, Bitwise, Encryption, Conversion, Signals, Networking, Misc) |
| **Exams/** | Exam solutions from Informática 1 at UTNBA — midterms, finals, recovery exams, and practice problems |
| **Book_Exercises/** | Solved exercises from *"How to Program in C"* by Deitel & Deitel |
| **Reference_Docs/** | Reference PDFs and documentation in English and Spanish |
| **Theory_Notes/** | Theory notes and study materials for exam preparation |

---

## Libraries Overview

| Module | Description |
|---|---|
| `Strings/` | Custom string manipulation functions (copy, compare, tokenize, etc.) |
| `Sorting/` | Sorting algorithms (bubble sort, selection sort, insertion sort, etc.) |
| `LinkedLists/` | Singly/doubly linked lists, queues, stacks, and recursive algorithms |
| `Matrix/` | Matrix operations (creation, transposition, multiplication, etc.) |
| `FileIO/` | File handling utilities: binary read/write, copy, rename, filtering |
| `Math/` | Mathematical functions |
| `Bitwise/` | Bitwise operation utilities |
| `Encryption/` | String encryption/decryption functions |
| `Conversion/` | Integer-to-string and string-to-long conversions |
| `Signals/` | UNIX signal handling examples |
| `Networking/` | Socket library and server-client implementation |
| `Misc/` | Miscellaneous utilities (random numbers, array reversal, etc.) |
