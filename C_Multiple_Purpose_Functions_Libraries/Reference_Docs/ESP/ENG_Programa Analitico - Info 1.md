Thematic Unit 1. Structure of a Computer
Historical background. Definition of fundamental units (bit and byte) and their multiples. 
Definition of memory. Memory capacity. Types of memory. Buses. Central Unit of the 
Process (C.P.U). Arithmetic and Logic Unit (ALU). Control Unit. Program Counter. 
Input/output (I/O) devices. Execution of instructions. Search phase 
instructions. Instruction Sequence: Program. Hardware and Software Concepts. 
Interaction between both elements. 
Assimilation of the theoretical concepts stated in the theoretical model, so that students  
can tangibly verify them on different platforms: PC, Embedded PC, 
Microcontrollers.
Supporting Bibliography: Essentials of Computer Organization and Architecture. Linda Null & Julia Lobur. Pennsylvania  
StateUniversity. Jones and Bartlett Publishers. Chapter 1
Thematic Unit 2. Numbering Systems and Numerical Representation. 
Binary Arithmetic 
Introduction. Numbering systems and their historical evolution. 
Decimal, binary, octal and hexadecimal numbering systems. Passages between systems 
integers and positive numbers. 
Representation of signed numbers: Agreement of sign and magnitude. Complement agreement  
to one. Two's complement agreement. Addition and subtraction operations using the 
two's complement agreement. 
Representation of fractional numbers. Fixed point and floating point notation. Precision and 
truncated. Errors in floating point notation. IEEE 754 format.
Character representation: Binary Coded Decimal (BCD), ASCII, EBCDIC, Unicode.
Codes for Data Transmission and Recording: Non-Return to Zero Coding, Coding  
by Inverted Non-Return to Zero, Phase Modulation (Manchester Coding), Modulation in 
Frequency, Run Length Limited Code (RLL).
