Como único Sistema Operativo 
Instalación: Se instala a partir del arranque de un pendrive en el 
disco rígido de la computadora. Utiliza todo el disco rígido. 
Funcionamiento:  La máquina arranca con Linux, funciona con 
Linux y se apaga con Linux. 
Ventajas:  Linux toma el control total del hardware, obteniendo 
buenos resultados de performance. Puedo usar hardware viejo. 
Desventajas:  No puedo ejecutar aplicaciones Windows.

Dual boot (Windows/Linux) 
Instalación:  Se instala a partir del arranque de un pendrive en una 
parte del disco rígido de la computadora. Una parte del disco es 
para Linux, la otra para Windows. 
Linux reconoce y usa la parte Windows. Windows no reconoce la 
parte Linux. 
Debo tener Windows instalado cuando instale Linux. 
Funcionamiento:  Al arrancar aparece un menú para seleccionar el 
sistema operativo con el que arrancar. Trabajando en Linux es 
igual que si estuviera solo. 
Ventajas:  Linux toma el control total del hardware, obteniendo 
buenos resultados de performance. 
Desventajas: Para cambiar de Sistema Operativo, debo reiniciar el 
equipo.

Maquina virtual 
Instalación:  Se debe instalar un software de virtualización (por 
ejemplo VirtualBox de Oracle) conﬁgurar una máquina virtual y 
luego instalar Linux en esa máquina virtual. Para esa máquina 
virtual, Linux sería el único sistema operativo. 
Funcionamiento:  Para usar Linux, debo arrancar la máquina virtual. 
Linux cree que está corriendo solo en una máquina ﬁsica, pero en 
realidad es un programa, entonces cuando Linux debe acceder al 
hardware, se lo pide al software de la máquina virtual, el software 
de la máquina virtual se lo pide a Windows y Windows se lo pide al 
hardware físico.

Maquina virtual (continuación) 
Ventajas:  Es práctico, manejo todo dentro de 
Windows. 
Desventajas:  Requiero un hardware poderoso, 
porque la performance en la máquina virtual baja 
notablemente frente a correr Linux nativo. 
Linux se ve afectado por los problemas de 
performance de Windows. 
Cuando inicio la máquina virtual, los recursos de 
hardware deﬁnidos quedan reservados para la 
máquina virtual y se los saca a Windows (por 
ejemplo, tengo 4Gb de ram, armé una máquina 
virtual con 2Gb, cuando la arranco, Windows queda 
solo con 2Gb). 
Live
Instalación:  No se instala, arranco del pendrive cada vez que 
lo necesito. 
Funcionamiento:  Toma control del hardware y funciona 
como único Sistema Operativo. 
Ventajas:  No requiere instalación. 
Desventajas:  No puedo instalar aplicaciones, no puedo 
modiﬁcar la conﬁguración ya que cuando apago el equipo, 
todo se pierde.

Pendrive 
Instalación:  Se instala como único Sistema Operativo, pero 
en lugar de disco rígido, en un pendrive. 
Funcionamiento:  Fuciona igual que la instalación de único 
Sistema Operativo, con las limitaciones de almacenamiento 
correspondientes. 
Ventajas:  Es transportable, lo enchufo en cualquier 
computadora y lo trabajo desde ahí. 
Desventajas:  Suele funciona muy lento ya que el acceso al 
pendrive para todas las operaciones, degrada la 
performance.

ReplIt 
Instalación:  No se instala, accedo a una página web. 
Funcionamiento:  La página me presenta un editor de texto y 
una terminal sobre las que trabajar. Es una máquina virtual 
pero tiene buena performance. 
Ventajas:  No requiere instalación. Es portable. 
Desventajas:  Necesito estar conectado a Internet. 
No soy adminstrador del equipo por lo que no puedo instalar 
aplicaciones. 
Por seguridad de la página hay funciones que utilizaremos 
después de mitad de año que no estarán disponibles.
