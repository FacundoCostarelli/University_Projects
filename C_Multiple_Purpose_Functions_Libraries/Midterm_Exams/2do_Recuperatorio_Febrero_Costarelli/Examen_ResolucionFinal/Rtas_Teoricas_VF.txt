1)Un thread es la minima unidad de flujo de instrucciones que tiene un programa y que a su vez es planificado por el kernel a traves del shceduler. Es decir, un conjunto o flujo de isntrucciones como el que sigue seria un ejemplo de thread.

int a,b;
a = 10;
b = 20;
suma = a + b;

 En general un thread se lo asocia a una funcion, como por ejemplo con la funcion main(). Cualquier programa tiene al menos un thread, y en tal caso de tener procesos con un solo thread, este sera el asociado al flujo de instrucciones dado por main(). En otro caso, los threads pueden asociarse a varias funciones diferentes o iguales. Ej:

 void work()
 {
    printf("Esta funcion se asocia a un thread\n");
 }

Se puede decir de forma mejor que un thread es un flujo de instrucciones que puede correr de manera independiente respecto a otros flujos de instrucciones o threads.
Un thread es tambien la unidad basica de scheduling

EL thread mas basico y obligatorio que existe es el thread main(). Los threads comparten algunos recursos del proceso como FILES,SIGNAL,DATA y CODE. Pero poseen recursos propios como PC, STACK, REG. Entre threads pueden trabajar cooperativamente y tener un flujo de informacion de entre ellos debido a que comparten algunos recursos del proceso

Puede suceder que los threads se ejecuten en forma concurrente o en paralelo. 
El 1er caso corresponde a la ejecucion de varios threads en un single core tal que virtualmente se estan ejecutando todos al mismo tiempo pero fisicamente se estan ejecutando los thread de uno a la vez con intercalacion entre threads y respectivos time slots para cada thread. Esto nos permite tener un proceso con mas de 1 thread y una mejora importane en la velocidad y performance
 El 2do caso corresponde a la ejecucion de distintos threads repartidos en 2 o mas cores tal que se ejecutan al mismo tiempo. A su vez cada core tendra ejecucion en simultaneo o concurrencia. Ademas, cada thread tiene una planificacion diferente segun el scheduler tal que un thread se ejecuta en 1 core mientras que otro thread se ejecuta en otro core o tal que un thread se ejecuta en varios cores al mismo tiempo.
