# Bibliotecas de Funciones Multipropósito en C

## Descripción General

Este repositorio contiene una colección de **bibliotecas utilitarias reutilizables en C**, **resoluciones de exámenes**, **ejercicios de libro** y **material de referencia** desarrollados durante la cursada de **Informática 1** en la **Universidad Tecnológica Nacional — Buenos Aires (UTNBA)** en el año **2022**.

Funciona como un portfolio profesional de habilidades de programación en C, abarcando estructuras de datos, manejo de archivos, programación de sockets (networking), algoritmos de ordenamiento, manipulación de strings, y más.

> 📖 Para la versión en inglés de este documento, ver [README_ENG.md](README_ENG.md).

---

## Estructura del Repositorio

| Carpeta | Descripción |
|---|---|
| **Libraries/** | Funciones utilitarias reutilizables en C organizadas por tema (Strings, Sorting, LinkedLists, Matrix, FileIO, Math, Bitwise, Encryption, Conversion, Signals, Networking, Misc) |
| **Exams/** | Resoluciones de exámenes de Informática 1 en UTNBA — parciales, finales, recuperatorios y ejercicios de práctica |
| **Book_Exercises/** | Ejercicios resueltos del libro *"Cómo Programar en C"* de Deitel & Deitel |
| **Reference_Docs/** | PDFs de referencia y documentación en inglés y español |
| **Theory_Notes/** | Apuntes de teoría y materiales de estudio para la preparación de exámenes |

---

## Resumen de Bibliotecas

| Módulo | Descripción |
|---|---|
| `Strings/` | Funciones de manipulación de strings (copiar, comparar, tokenizar, etc.) |
| `Sorting/` | Algoritmos de ordenamiento (burbuja, selección, inserción, etc.) |
| `LinkedLists/` | Listas enlazadas simples/dobles, colas, pilas y algoritmos recursivos |
| `Matrix/` | Operaciones con matrices (creación, transposición, multiplicación, etc.) |
| `FileIO/` | Utilidades de manejo de archivos: lectura/escritura binaria, copia, renombrado, filtrado |
| `Math/` | Funciones matemáticas |
| `Bitwise/` | Utilidades de operaciones a nivel de bits |
| `Encryption/` | Funciones de encriptación/desencriptación de strings |
| `Conversion/` | Conversiones entero-a-string y string-a-long |
| `Signals/` | Ejemplos de manejo de señales UNIX |
| `Networking/` | Biblioteca de sockets e implementación servidor-cliente |
| `Misc/` | Utilidades varias (números aleatorios, inversión de arrays, etc.) |
