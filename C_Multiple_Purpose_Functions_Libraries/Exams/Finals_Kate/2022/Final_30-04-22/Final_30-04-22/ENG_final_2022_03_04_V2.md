1) void process_data(union logic_in *din, union logic_out *dout);
Receives a din pointer to a union of type logic_in and sets the corresponding bits in the union of type 
logic_out pointed by dout. The dout union has the following format:
union logic_out {
    unsigned chardata;
    struct {
            unsigned int out0 :1;
            unsigned int out1 :1;
            unsigned int out2 :1;
            unsigned int out3 :1;
            unsigned int out4 :1;
            unsigned int out5 :1;
            unsigned int out6 :1;
            unsigned int out7 :1;
           } output;
    };
The logic will be the following:
•out0 will be 1 if all bits ch0, ch1, ch2 and ch3 are equal to each other. That is, they are all 1 or all 0.
•out1 will be 1 if all bits ch4, ch5, ch6 and ch7 are equal to each other. That is, they are all 1 or all 0.
•out2 will be 1 if all bits ch8, ch9, ch10 and ch11 are equal to each other. That is, they are all 1 or all 0.
•out3 will be 1 if all bits ch12, ch13, ch14 and ch15 are equal to each other. That is, they are all 1 or all 0.
•out4 will be 1 if all bits ch0, ch1, ch2 and ch3 are 0.
•out5 will be 1 if all bits ch4, ch5, ch6 and ch7 are 0.
•out6 will be 1 if all bits ch8, ch9, ch10 and ch11 are 0.
•out7 will be 1 if all bits ch12, ch13, ch14 and ch15 are 0.

4) ./plogic <input_arch> <output_arch>
Create a program that receives the name of an input file with the data via command line 
coming from the logic analyzer and the name of an output file where the processed data can be saved.
The program must do the following:
- Validate the number of command line arguments. In case of error it will end with EARGS error.
- Open the input file from which to read the data. In case of error it will end with EINFILE error.
- Open the output file where the processed data will be written. In case of error it will end with error 
EOUTFILE.
- For each of the data read: 
1) process_data will be called
2) compute_zeroes will be called 
3) the processed data will be written to the output file
4) the totalizer of processed samples will be increased
- Once all the data has been processed, print_stats will be called to print the statistics.
- The program ends by returning OK
