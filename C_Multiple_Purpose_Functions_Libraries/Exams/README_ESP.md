# Exámenes — Informática 1 (UTNBA)

Resoluciones de exámenes de la materia **Informática 1** en la **Universidad Tecnológica Nacional — Buenos Aires (UTNBA)**, abarcando el período 2021–2023.

## Estructura

| Carpeta | Descripción |
|---|---|
| **Midterms/** | Resoluciones de parciales |
| ├─ `2022_Midterm1/` | 1er parcial, 2022 (versiones V1 y final + fotos del examen) |
| └─ `2023_Feb_Recovery/` | 2do recuperatorio del 2do parcial, febrero 2023 (solución original y final) |
| **Finals_Kate/** | Resoluciones de finales desarrolladas en el editor de texto Kate |
| ├─ `2021/`, `2022/`, `2023/` | Organizados por año |
| **Finals_Qt/** | Resoluciones de finales desarrolladas en Qt Creator IDE |
| ├─ `2021/`, `2022/`, `2023/` | Organizados por año |
| **Finals_Own/** | Examen final propio del autor |
| └─ `2023_May/` | Examen final, 24 de mayo de 2023 |
| **Practice/** | Exámenes y ejercicios de práctica |
| ├─ `Midterm1_2019/` | Práctica de 1er parcial (2019) |
| ├─ `Midterm1_2022/` | Modelo de 1er parcial (2022) |
| ├─ `Midterm1_2_2021/` | Ejercicios de 1er y 2do parcial (2021) |
| ├─ `Midterm2_Nov2022/` | 2do parcial, noviembre 2022 |
| └─ `Recovery1_Dec2022/` | 1er recuperatorio del 2do parcial, diciembre 2022 |

## Notas

- Las soluciones fueron desarrolladas originalmente en **Linux** usando **GCC**, **Kate** y **Qt Creator**.
- Cada carpeta de examen puede contener el PDF del examen, código fuente (`.c`, `.h`) y archivos de compilación.
