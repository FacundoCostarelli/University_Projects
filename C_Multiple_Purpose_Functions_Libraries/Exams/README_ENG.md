# Exams — Informática 1 (UTNBA)

Exam solutions from the **Informática 1** course at **Universidad Tecnológica Nacional — Buenos Aires (UTNBA)**, spanning 2021–2023.

## Structure

| Folder | Description |
|---|---|
| **Midterms/** | Midterm exam solutions |
| ├─ `2022_Midterm1/` | 1st midterm exam, 2022 (V1 and final versions + exam photos) |
| └─ `2023_Feb_Recovery/` | 2nd midterm recovery exam, February 2023 (original and final solutions) |
| **Finals_Kate/** | Final exam solutions developed in Kate text editor |
| ├─ `2021/`, `2022/`, `2023/` | Organized by year |
| **Finals_Qt/** | Final exam solutions developed in Qt Creator IDE |
| ├─ `2021/`, `2022/`, `2023/` | Organized by year |
| **Finals_Own/** | The author's own final exam |
| └─ `2023_May/` | Final exam, May 24, 2023 |
| **Practice/** | Practice exams and exercises |
| ├─ `Midterm1_2019/` | 1st midterm practice (2019) |
| ├─ `Midterm1_2022/` | 1st midterm model (2022) |
| ├─ `Midterm1_2_2021/` | 1st and 2nd midterm exercises (2021) |
| ├─ `Midterm2_Nov2022/` | 2nd midterm, November 2022 |
| └─ `Recovery1_Dec2022/` | 1st recovery of 2nd midterm, December 2022 |

## Notes

- Solutions were originally developed on **Linux** using **GCC**, **Kate**, and **Qt Creator**.
- Each exam folder may contain the exam PDF, source code (`.c`, `.h`), and build artifacts.
