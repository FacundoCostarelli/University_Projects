Punto 2) Indique cuáles de las siguientes afirmaciones son verdaderas:
[ENG] Point 2) Indicate which of the following statements are true:

A. Linux maneja los dispositivos como si fueran un archivo y el encargado de hacerlo para cada
dispositivo es el device driver o controlador del dispositivo.
[ENG] A. Linux handles devices as if they were files, managed through their specific device drivers.
B. Una desventaja del método de complemento a 1 para la representación de números signados
es que tengo un doble cero.
[ENG] B. A disadvantage of the ones' complement method for signed integers representation is having a double zero.
C. Todos los procesos tienen un solo proceso padre y pueden ser padres de un solo proceso
hijos a la vez. Si quiero tener un segundo proceso hijo, debo esperar a que finalice el primero
con la función wait.
[ENG] C. All processes have only one parent and can only have one child process at a time. If I want a second child, I must wait for the first to finish using the wait function.
D. Para generar un ejecutable a partir de un archivo fuente en C debo realizar dos pasos. El
primero es la compilación y el segundo es el linkeo o enlace.
[ENG] D. To generate an executable from a C source file, two steps are required: compilation and linking.
E. Para generar un programa en C puedo usar un procesador de texto como el word si me
aseguro de no ponerle ningún formato como cambio de tamaño de letra o negrita.
[ENG] E. To write a C program, I can use a word processor like Word as long as I don't apply formatting (like font resizing or bolding).
F. Los archivos en Linux manejan tres grupos de permisos, los correspondientes al dueño, a un
grupo y al resto de los usuarios.
[ENG] F. Linux files define three permission groups: owner, group, and others.
G. No se puede establecer una conexión a través de un socket si ambos procesos se ejecutan
en la misma máquina.
[ENG] G. A socket connection cannot be established if both processes are running on the same machine.
H. El sistema de numeración está definido por la cantidad de símbolos que utiliza. Esta cantidad
se llama BASE.
[ENG] H. The numbering system is defined by the number of symbols it uses, called the BASE.
I. El named pipe o FIFO es un método de IPC que permite vincular dos procesos que se
ejecuten en la misma máquina aunque no estén relacionados como padre-hijo.
[ENG] I. A named pipe (FIFO) is an IPC method allowing linkage between two completely unrelated processes on the same machine.
J. La ventaja de trabajar con el sistema HEXADECIMAL es que la conversión desde binario es
directa a partir de la agrupación de tres dígitos binarios.
[ENG] J. The advantage of working with the HEXADECIMAL system is that conversion from binary is direct by grouping three binary digits.
K. En el caso de Linux, la interfaz gráfica la puedo cambiar e incluso eliminarla.
[ENG] K. On Linux, the graphical interface can be swapped or completely removed.
L. Los procesos se identifican con un número, y una vez que se asignó el número mayor, hay
que reiniciar el equipo para volver el contador a 0.
[ENG] L. Processes are identified by numbers. Once the maximum number is reached, the system must be rebooted to reset the counter to 0.
M. Si la máquina tiene la suficiente capacidad, puedo tener dos Sistemas Operativos controlando
el hardware simultáneamente.
[ENG] M. If the machine is powerful enough, I can have two Operating Systems controlling the hardware natively simultaneously.
N. El Sistema Operativo se conecta con el hardware a través de las system calls.
[ENG] N. The Operating System connects with the hardware via system calls.
O. En una conexión vía Socket, cuando un proceso servidor quiere aceptar la comunicación con
un cliente, debe usar la función connect.
[ENG] O. In a Socket connection, when a server process wants to accept communication with a client, it must use the connect function.
