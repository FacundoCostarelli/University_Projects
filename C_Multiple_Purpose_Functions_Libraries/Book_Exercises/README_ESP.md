# Ejercicios del Libro — "Cómo Programar en C" (Deitel & Deitel)

Ejercicios resueltos del libro **"Cómo Programar en C"** de Paul Deitel y Harvey Deitel, utilizado como referencia principal en **Informática 1** en la **UTNBA (2022)**.

## Contenido

- **Deitel_HowToProgramInC.pdf** — El libro de texto (edición en español)
- **Ex2-03/ a Ex3-23/** — Soluciones de ejercicios individuales

## Compilación

Cada carpeta de ejercicio contiene un archivo `.c` que puede compilarse con:

```bash
gcc -o ejercicio ExN-NN.c -Wall
./ejercicio
```
