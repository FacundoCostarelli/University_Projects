# Book Exercises — "How to Program in C" (Deitel & Deitel)

Solved exercises from the textbook **"How to Program in C"** by Paul Deitel and Harvey Deitel, used as the primary reference for **Informática 1** at **UTNBA (2022)**.

- **Deitel_HowToProgramInC.pdf** — The textbook (Spanish edition)
- **Ex2-03/ through Ex3-23/** — Individual exercise solutions

## Compilation

Each exercise folder contains a `.c` file that can be compiled with:

```bash
gcc -o exercise ExN-NN.c -Wall
./exercise
```
