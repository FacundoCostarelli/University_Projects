8)Una "pipe" es una "system call" que crea un link de comunicacion unidireccional entre 2 files descriptos. Se dice que en la "input" de la pipe se escribe informacion y en el "output" de la pipe se lee informacion. 

Las pipes se usan para intercomunicar procesos "parent y child" donde uno de ellos comanda el input y otro el output. Habitualmente el proceso padre comanda el output y el proceso hijo el input. Tambien se puede usar entre 2 procesos hijos. Vemos que en sintesis se usa entre 2 procesos.

9)prototipo para crear una pipe: int pipe(int pipefd[2]);

Este prototipo recibe un array de 2 elementos llamado "pipefd". Esto significa que lo que se le pasa a la funcion es el nombre de un vector el cual es un puntero simple(un solo *) que apunta al 1er elemento de dicho array. En particular, los elementos de este array son 2 valores ints asociados a un file descripto cada uno. En este caso, el 1er elemento se asocia al input en  la pipe, es decir, un fd para escritura y el 2do al output de la pipe, es decir, un fd para la lectura en la pipe

Socket para UDP se los llama Socket Datagram y se usa en un contexto tal que se provee un flujo de datos bidireccional, no orientado a conexion, no secuenciado el orden de llegada de paquetes, posibilidad de perdida de paquetes y errores 

Socket para TCP se los llama Socket Stream y se usan en un contexto tal que se provee un flujo de datos bidireccional, orientado a conexión, secuenciado el orden de llegada de paquetes, sin duplicación de paquetes y libre de errores
